# تطبيق جمعية أولياء التلاميذ إبتدائية الشيخ حاج مسعود سعيد

## معلومات المشروع
- **الموقع**: بلدية العطف - تجنينت - ولاية غرداية
- **الموسم الدراسي**: 2026/2027
- **نوع التطبيق**: PWA (Progressive Web App)

## أقسام التطبيق

### 1. الرئيسية
- صفحة ترحيبية بأيقونة الجمعية
- وصول سريع لجميع الأقسام

### 2. الأدوات المدرسية
- قائمة كاملة للأدوات المدرسية لكل مستوى
- من السنة الأولى إلى السنة الخامسة ابتدائي
- إمكانية تحديد الأدوات المُحضّرة (حفظ تلقائي)

### 3. منشورات الفايسبوك
- عرض آخر منشورات صفحة الجمعية على الفايسبوك
- رابط مباشر للصفحة الرسمية
- تحديث تلقائي للمنشورات

### 4. أرشيف الجمعية
- نشاطات المواسم السابقة
- عرض حسب السنوات الدراسية

### 5. إشعارات المدرسة
- إشعارات فورية لل объявлارات والتنبيهات
- تفعيل/تعطيل الإشعارات
- 3 مستويات: عادي، مهم، عاجل

### 6. المواقع التربوية
- المواقع الرسمية لوزارة التربية الوطنية
- فيديوهات تعليمية للمستوى الابتدائي

### 7. لوحة التحكم (للإدارة)
- إضافة إشعارات جديدة
- إدارة الإشعارات الحالية
- تحديث قوائم الأدوات المدرسية

## كيفية التشغيل

### للتجربة المحلية
1. افتح مجلد المشروع في المتصفح
2. افتح ملف `index.html`

### للنشر على الإنترنت
1. ارفع جميع الملفات على استضافة ويب
2. تأكد من تفعيل HTTPS (مطلوب لـ PWA)
3. سيتم تثبيت التطبيق تلقائياً على أجهزة المستخدمين

## ملاحظات مهمة

### حول ملف PDF المرفق
لا يمكن قراءة ملف PDF مباشرة من هذا النموذج. يرجى:
1. فتح ملف `data.js`
2. تعديل مصفوفة `GRADES_DATA` بإضافة الأدوات المدرسية من الملف
3. كل مستوى له مفتاح: `grade1` إلى `grade5`

### حول صفحة الفايسبوك
التطبيق يعرض منشورات تجريبية. للربط الحقيقي بفيسبوك:
1. استخدم Facebook Graph API
2. أو استخدم Facebook Page Plugin
3. أو قم بدمج iframe لصفحة الفايسبوك
